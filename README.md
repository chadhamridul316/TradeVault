A MERN-based prop-firm trading challenge simulator.

## Features
- User authentication
- Prop-firm challenge simulation
- Trade management
- Challenge rules and validation
- Drawdown tracking
- Analytics dashboard
- Trading journal
- AI Performance Analyzer

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose

AI:
- OpenAI API

## Architecture

Frontend
   ↓
Express API
   ↓
Controllers
   ↓
MongoDB

AI Performance Analyzer:

Frontend
